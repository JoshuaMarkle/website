Better Canvas

A small personal tool by Joshua Markle.

Better Canvas syncs assignments from a Canvas calendar feed and from course websites into a dedicated Google Tasks list. It removes non-assignment noise (such as Zoom links), shows courses by nickname, and keeps deadlines up to date so changes carry over automatically.

Google access

Better Canvas uses Google sign-in only to create, update, and delete tasks in the user's Google Tasks (scope https://www.googleapis.com/auth/tasks). It is used personally by its developer and does not collect, store, or share any user data.
