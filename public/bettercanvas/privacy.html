Privacy Policy

Better Canvas · Last updated: October 10, 2026

Better Canvas is a personal tool operated by Joshua Markle for his own use.

Data collection

Better Canvas does not collect, sell, share, or transmit any personal data to the developer or to any third party. There are no analytics, ads, or tracking.

Google user data

The app requests access to Google Tasks (https://www.googleapis.com/auth/tasks) solely to create, update, and delete assignment tasks in the signed-in user's own account. Data accessed through this scope is used only for that purpose, is not used for advertising, is not transferred to anyone, and is not read by humans. Better Canvas's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage

Authentication tokens and sync state are kept privately by the developer and are used only to run the sync. Access can be revoked at any time at myaccount.google.com/permissions.
